# 📚 DSA Revision Notes

This repository is meant for **quick interview revision**, not learning from scratch.

Every note should answer these questions:

1. **When should I recognize this pattern?**
2. **What's the core idea?**
3. **Why does this approach work?**
4. **What edge cases should I remember?**
5. **Why is the complexity O(...) ?**
6. **What's the one-line memory hook?**
